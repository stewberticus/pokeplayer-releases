# pokeplayer downloads

pokeplayer plays Pokémon Red, Blue, Gold, Silver and Crystal with you through
conversation. This repository holds only its downloads; the source is private.

**[Download the latest Mac version](https://github.com/stewberticus/pokeplayer-releases/releases/latest/download/pokeplayer-mac-arm64.dmg)**
(Apple Silicon, macOS 14 or later)

Each [release](https://github.com/stewberticus/pokeplayer-releases/releases)
carries its notes, a start guide for each platform (`MAC-START-HERE.md`,
`WINDOWS-START-HERE.md`) and `SHA256SUMS.txt`. You supply your own game ROM.
